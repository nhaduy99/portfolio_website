# Portfolio media

Use profile/images/ for portraits. Research and project folders each contain images/ and videos/.

## Upload instructions

Open the relevant folder, choose **Add file → Upload files**, upload your files and commit. Add captions and credits to that folder's README. Use descriptive lowercase filenames with hyphens. Prefer JPG/WebP photographs, PNG figures and MP4 (H.264/AAC) video. Aim for images below 2 MB and short clips below 20 MB; these are web recommendations, not GitHub limits. For larger videos, add a viewing link and caption instead.

This repository is public. Upload media suitable for public display. Include your contribution and any necessary credits; for research figures state units and whether results are experimental or simulated.

Uploads do not automatically update the website. The ChatGPT Sites portfolio is maintained separately. After uploading, tell me which sections changed so I can integrate the media and republish. Existing website image references are unchanged.
