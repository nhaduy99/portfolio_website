01 LAB AUTOMATION / PROTOTYPE

AI Box

A practical interface between laboratory hardware and software.

Python and Flask tools control three pumps and a linear actuator, alongside live TCS34725 colour-sensor readings. Independent PWM, direction and stop controls support hardware testing.

Python Flask Raspberry Pi Sensor integration
Engineering details

The repository includes dry-run operation when the MotorKit driver is unavailable, standalone sensor tests and CSV export. Hardware validation and calibration are part of the prototype workflow.

View project source ↗
Problem
Laboratory components need a usable control interface.
Contribution
Python/Flask controls for pumps, an actuator and colour sensing.
Output
A hardware-testing interface with sensor readings and CSV export.
02 BIOPROCESS CONTROL / FIRMWARE

ePBR Controller

Embedded control for experimental photobioreactors.

Arduino firmware brings temperature and jacket-temperature readings, LED intensity, fans, thermal actuation and an air-valve relay into a serial-command interface.

C++ Arduino PWM Serial protocols
Engineering details

Includes bounded command parsing, immediate and newline-terminated commands, and initial output states. Temperature conversion uses a configurable calibration model that must be calibrated for the actual hardware.

View project source ↗
Problem
Cultivation experiments require coordinated sensing and actuation.
Contribution
Arduino firmware for temperature, lighting, airflow and thermal control.
Output
A serial-command interface for experimental photobioreactors.
03 APPLIED MACHINE LEARNING / RESEARCH

Spectral Soft Sensors

Learning chemical information from complementary measurements.

A Python research pipeline combining Raman and excitation–emission fluorescence features to investigate prediction of glucose, xylose and rhamnose concentrations.

Python NumPy Feature engineering Multimodal fusion
Engineering details

Code supports modality merging, interpretable and full-spectrum feature sets, target parsing and model comparisons. This is research code; predictive performance depends on the dataset and validation design.

View project source ↗
Problem
Chemical information is distributed across complementary spectra.
Contribution
Feature engineering and model comparisons using Raman and fluorescence measurements.
Output
A research pipeline for investigating sugar-concentration prediction.
04 SCIENTIFIC SOFTWARE / DECISION SUPPORT

Algae Inoculation Agent

Turning literature records into experimental options.

A Python tool ranks literature-derived growth conditions against species, objectives and laboratory constraints, then produces structured JSON and readable experiment reports.

Python Browser UI Evidence scoring JSON
Engineering details

Includes an interactive interface and optional Google Drive PDF import. The scoring engine consumes literature records; it does not independently search the literature, and extracted records require review.

View project source ↗
Problem
Literature findings need to become practical experimental options.
Contribution
Constraint-based ranking of literature-derived growth conditions.
Output
Structured experiment reports for researcher review.
